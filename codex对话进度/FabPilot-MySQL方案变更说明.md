# FabPilot 数据库方案变更说明

> 状态：已生效  
> 日期：2026-08-04  
> 优先级：本说明优先于《FabPilot-项目设计与开发交接文档》中所有 PostgreSQL、pgvector 相关表述。

## 决策

FabPilot MVP 的业务、审批、审计、SOP 元数据及 Agent 运行数据统一使用 **MySQL 8.0**。

## MVP 实现调整

- 通过 MySQL InnoDB 实现事务、外键（按实际表设计采用）、唯一约束与乐观锁版本字段。
- 使用 Flyway 管理数据库迁移与种子数据。
- SOP 知识库采用 MySQL `FULLTEXT` 检索与设备类型、工序、报警码、文档状态及有效期等元数据过滤。
- 不在 MVP 中使用 PostgreSQL、pgvector 或任何向量数据库。
- 第一阶段的检索目标是：能为固定异常演示场景返回正确且可引用的 SOP 片段。

## 第二阶段

基础关键词检索完成评测后，再选择向量检索路线：优先评估 MySQL 的向量能力；若检索质量、运维成本或生态不合适，再单独引入向量检索组件。该选择必须新增 ADR 后才能实施。

## 不受影响的设计

- Spring Boot MES Core 仍是唯一业务事实来源。
- Agent 仍只具备查询、诊断、提议与验证能力，不能直写业务数据库。
- Lot 双状态、不可变 LotTransaction、审批、幂等、乐观锁和审计规则均不变。
